# Lino 九状态原画动画设计

## 1 目标

使用用户提供的九宫格原画替换现有的“固定云朵图片加 CSS 表情覆盖层”。Mood 界面展示九种与原画一一对应的状态，并通过状态专属运动和弹性切换增强角色的灵动感。

## 2 原画状态映射

整张 `1254 × 1254` 图片按 `3 × 3` 网格作为精灵图使用，不重新描摹五官、手势、腮红或装饰符号。

| 位置 | 状态标识 | 中文名称 | 动作表现 |
| --- | --- | --- | --- |
| 第一行第一列 | `idle` | 平静 | 缓慢呼吸、轻微上下悬浮 |
| 第一行第二列 | `happy` | 高兴 | 弹跳、落地时轻微压缩 |
| 第一行第三列 | `playful` | 顽皮 | 左右歪头、短促侧跳 |
| 第二行第一列 | `curious` | 好奇 | 向问号方向倾斜、停顿观察 |
| 第二行第二列 | `shy` | 害羞 | 小幅收拢、左右轻摆 |
| 第二行第三列 | `surprised` | 惊讶 | 快速后仰、回弹并停顿 |
| 第三行第一列 | `thinking` | 思考 | 缓慢歪头、上下浮动 |
| 第三行第二列 | `proud` | 坚定 | 向上弹起、轻微前倾 |
| 第三行第三列 | `sleepy` | 困倦 | 缓慢点头、下沉后恢复 |

## 3 渲染方案

`LinoMascot` 使用带裁切窗口的精灵容器。内部图片保持原始比例并放大到容器的三倍，通过行列坐标移动到对应帧。白色画布使用混合模式与现有白色界面融合，不切割、生成或修改原画文件。

状态变化时，旧帧淡出并缩小，新帧以轻微弹性放大进入。循环动作仅使用位移、缩放和旋转，避免模糊精灵线条。`prefers-reduced-motion` 下直接切换帧，不播放循环和过渡动作。

现有 CSS 五官覆盖层和动作线全部移除，避免角色出现贴片感。

## 4 Mood 交互

Mood 右侧由五个情绪条扩展为九个状态条，名称和缩略图均与九宫格一致。点击任一状态条后，主 Lino 立即切换对应原画和动作，并更新 `Feeling` 文案及选中状态。

点击主 Lino 时，从九种状态中随机选择一个与当前状态不同的状态。对话生成期间继续使用 `thinking`，完成后继续使用 `proud`。

环境随机状态使用九种状态，但提高 `idle` 权重，避免界面持续跳动。用户主动选择的状态仍写入现有本地存储。

## 5 兼容处理

本地存储版本保持不变。旧状态 `sad` 恢复时转换为 `shy`，旧状态 `angry` 恢复时转换为 `proud`；其他仍存在的状态直接保留。

原图为不透明 RGB 图片。当前方案依赖白色或接近白色的界面背景，并使用 `mix-blend-mode: multiply` 弱化方形白底。如果后续需要深色主题，应另行制作透明背景精灵。

## 6 测试与验收

1. 九个状态条均可见，并分别产生正确的 `data-state`、精灵行列和动态文案。
2. 点击主 Lino 后，新状态与点击前不同。
3. 思考和完成对话分别显示 `thinking` 与 `proud` 原画。
4. 旧的 `sad`、`angry` 本地状态能够安全迁移。
5. 减少动态模式下不执行循环动作。
6. 桌面和 `390 × 844` 手机视口无新增溢出或重叠。
7. 页面无控制台错误，原图在 Mood 主角色、状态缩略图、页头和对话头像中均保持可识别。
